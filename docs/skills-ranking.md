# 自作スキル - 汎用性・実用性ランキング

## S級（最高レベル - どのプロジェクトでも必須）

### 1. commit
**用途**: Conventional Commits自動作成（emoji付き）
**汎用性**: ★★★★★ - Git使用プロジェクト全般
**実用性**: ★★★★★ - 毎日使用、コミット履歴の品質向上
**特徴**: 
- 対話的な型・スコープ選択
- emoji自動付与
- git diff自動確認
- コミットメッセージ履歴参照

### 2. validate
**用途**: 多層品質ゲート検証（構文・フォーマット・セキュリティ）
**汎用性**: ★★★★★ - 技術スタック横断的
**実用性**: ★★★★★ - 実装完了後の必須チェック
**特徴**:
- Layer 1-2: TypeScript/ESLint/Prettier自動修正
- Layer 5: セキュリティ検証（OWASP Top 10）
- 26ファイルの完全なテストスイート
- `--auto-fix`で自動修正

### 3. decide
**用途**: 意思決定支援（ICE/RICE/First Principles）
**汎用性**: ★★★★★ - 技術選定・機能優先順位付け全般
**実用性**: ★★★★★ - 実装前の意思決定に必須
**特徴**:
- ICE Score自動計算
- frameworks.md で詳細ガイド提供
- アンチパターン集
- YAGNI原則適用

### 4. ship
**用途**: GitHub PR/GitLab MR作成自動化
**汎用性**: ★★★★★ - GitHub/GitLab使用プロジェクト全般
**実用性**: ★★★★★ - PR/MR作成の手間削減
**特徴**:
- プラットフォーム自動検出
- git diff自動要約
- テストチェック
- レビュアー提案

### 5. worktree
**用途**: Git worktree管理（並行開発）
**汎用性**: ★★★★★ - Git使用プロジェクト全般
**実用性**: ★★★★☆ - 複数機能並行開発時に有用
**特徴**:
- create/list/switch/merge/delete/status
- パス検証・セキュリティ対策
- ポート管理（3001, 3002...）

## A級（高レベル - 多くのプロジェクトで有用）

### 6. implement
**用途**: tasks.yml駆動実装（ドキュメント自動注入）
**汎用性**: ★★★★☆ - ドキュメント重視プロジェクト
**実用性**: ★★★★★ - タスク管理の効率化
**特徴**:
- tasks.schema.json でバリデーション
- docs自動読み込み
- acceptance_criteria自動管理
- Interactive Mode

### 7. todo
**用途**: 個人タスク管理（todo.md）
**汎用性**: ★★★★★ - どのプロジェクトでも使える
**実用性**: ★★★★☆ - 軽量で手軽
**特徴**:
- Markdown checklist形式
- priority/tags/due date対応
- tasks.yml同期機能
- todo_validation.py でセキュリティ検証

### 8. branch
**用途**: Conventional Branch命名規則
**汎用性**: ★★★★★ - Git使用プロジェクト全般
**実用性**: ★★★★☆ - ブランチ命名の統一
**特徴**:
- feature/bugfix/hotfix/refactor自動プレフィックス
- worktree連携

### 9. review-pr
**用途**: PR/MRレビュー自動化
**汎用性**: ★★★★☆ - GitHub/GitLab使用プロジェクト
**実用性**: ★★★★★ - レビュー品質向上
**特徴**:
- セキュリティ最優先チェック
- コード品質評価
- 改善提案生成

### 10. iterative-review
**用途**: 多角的コードレビュー
**汎用性**: ★★★★★ - どの言語・プロジェクトでも
**実用性**: ★★★★☆ - コード品質向上
**特徴**:
- 必要性・セキュリティ・パフォーマンス・保守性の4軸
- Round形式の段階的レビュー

## 共有推奨スキル（上位10個）

他人への共有を推奨する順:

1. **commit** - 必須、どのプロジェクトでも即効果
2. **validate** - 品質向上、完全なテストスイート
3. **decide** - 意思決定効率化、フレームワーク充実
4. **ship** - PR/MR作成自動化、実用性高い
5. **worktree** - 並行開発、上級者向け
6. **implement** - タスク管理効率化、ドキュメント駆動
7. **todo** - 軽量タスク管理、シンプル
8. **branch** - ブランチ命名統一、簡単
9. **review-pr** - レビュー品質向上
10. **iterative-review** - コード品質向上
